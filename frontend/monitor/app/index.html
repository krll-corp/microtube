Про ці перевірки. Статуси відображають результат HTTP-запитів із браузера через внутрішній проксі. Зелений статус означає, що перевірений ендпоінт відповів успішно, але не гарантує, що кожна функція сервісу працює без помилок. Історія зберігається локально в цьому браузері.

Бази PostgreSQL та фоновий сервіс індексації не мають окремої HTTP-перевірки в цій версії. Для повного моніторингу потрібні окремі health-check або Prometheus/Grafana.
